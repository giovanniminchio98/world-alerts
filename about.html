About

Global Incident Map answers one question — “What is happening around this place right now?” — as honestly as public data allows.

Purpose

The site brings together recent earthquakes, major-disaster alerts, satellite thermal detections and U.S. weather alerts on one map, and lets you check what the connected sources report around any place. It aims to be transparent about what is monitored, when each source was last refreshed, and what is not covered.

It is a static website hosted on GitHub Pages. Data is refreshed by scheduled GitHub Actions workflows, so it is never real-time: it reflects the last published update, and data may be delayed.

Emergency disclaimer

This website aggregates third-party public data and may be delayed, incomplete, inaccurate, or unavailable. It is not an emergency warning system and must not be used as a substitute for official local authorities, emergency services, or safety instructions.

In an emergency, contact local emergency services and follow instructions from official authorities. The absence of an incident on this map never means a place is safe.

Privacy

  • No accounts, no sign-in, no advertising, no analytics and no tracking.
  • This project has no server or database, and never receives your location or searches.
  • “Use my location” is opt-in: your browser asks permission, and the coordinates are used only inside your browser to centre the map and build the location card.
  • Settings (units, time zone display, theme, filters) are stored only in your browser's local storage. Clearing site data removes them.
  • Clicked points are labelled offline using a bundled city list and country outlines — no request is made.
  • Third parties: to draw the basemap your browser requests map tiles from OpenFreeMap. When you submit a worldwide place search, the search text is sent to OpenStreetMap Nominatim (see the OSMF privacy policy). Suggestions while typing come from a built-in list and send nothing. These providers receive the normal technical information of any web request (such as your IP address). GitHub Pages hosts the site and may keep standard server logs.
